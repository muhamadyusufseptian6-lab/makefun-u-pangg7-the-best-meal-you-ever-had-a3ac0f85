One sentence, at most 200 characters, about the best meal I ever had — and the
kitchen I've been eating my way back to ever since: nasi goreng still crackling
from the wok, eaten barefoot on my grandmother's kitchen tiles in Jakarta, the
yolk running gold.

## How it works

`main.ts` (Node 22, stdlib only, deterministic) writes the sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no secrets, no input data.

```sh
node main.ts
node check.mjs
```
